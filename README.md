#Battery Monitoring System 🔋

Project Overview

This is a beginner-level Electrical Engineering project to learn about battery monitoring.

Objectives

- Understand battery voltage and current.
- Learn about battery temperature monitoring.
- Understand State of Charge (SOC).

Applications

- Electric vehicles
- Solar energy storage
- Battery-powered equipment

Project Status

Currently a learning and documentation project. Practical implementation and testing are future steps.

Python Simulation

This project includes a beginner-friendly Python simulation of a Battery Monitoring System.

Features

- Displays battery voltage.
- Displays battery current.
- Calculates electrical power using P = V × I.
- Displays a basic status message.

Sample Output

- Voltage: 12 V
- Current: 2 A
- Power: 24 W

Note: This is a software simulation. It does not measure a real battery.
